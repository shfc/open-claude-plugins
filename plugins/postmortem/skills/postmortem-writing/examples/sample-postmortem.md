# Postmortem: Fix token validation failing for password reset tokens

## Problem Summary

Users were unable to complete password reset flow after requesting password reset. The authentication service returned a 500 Internal Server Error when validating reset tokens. This affected all users who attempted password reset between 2026-01-08 and 2026-01-10, approximately 1,200 users.

## Root Cause Analysis

**Root cause category**: Logic Error

**Why it happened**:
- Token validation logic in `validate_token()` function assumed all tokens were exactly 32 characters long
- Original implementation only handled session tokens, which are always 32 characters (generated by session service)
- Password reset feature was added later, generating 64-character tokens for enhanced security
- Validation logic was never updated to handle variable-length tokens
- The hardcoded length check `if len(token) != 32` rejected all password reset tokens
- No comprehensive test suite existed to catch this edge case

**Modified files**:

- `src/auth/token_types.py`: 8 lines added (token type enum)

**Key logic changes**:
- Removed hardcoded 32-character length check in `validate_token()`
- Added flexible token length validation (16-128 characters)
- Introduced `TokenType` enum to distinguish session vs. reset tokens
- Added token type detection based on format and length
- Improved error messages to specify which validation step failed

**API/Interface changes**:
- `validate_token(token: str)` now accepts optional `token_type: TokenType` parameter
- Return value changed from `bool` to `TokenValidationResult` object containing:
  - `is_valid: bool`
  - `token_type: TokenType`
  - `error_message: Optional[str]`
- Added `get_token_type(token: str) -> TokenType` helper function

**Before**:
```python
def validate_token(token: str) -> bool:
    if len(token) != 32:
        return False
    # ... rest of validation
```

**After**:
```python
def validate_token(token: str, token_type: Optional[TokenType] = None) -> TokenValidationResult:
    # Detect token type if not provided
    if token_type is None:
        token_type = get_token_type(token)

    # Validate length based on token type
    if not (16 <= len(token) <= 128):
        return TokenValidationResult(
            is_valid=False,
            token_type=token_type,
            error_message=f"Token length {len(token)} out of valid range [16-128]"
        )

    # ... rest of validation
```
